Medical AI Computer Vision

Blood Cancer Detection System

Automated blood cell analysis system using ResNet50 feature extraction, supervised ML classifiers, YOLOv8 object detection, and Grad-CAM explainability for interpretable medical image analysis.

  • Processed 5,000 microscopic blood cell images across five categories.
  • Used ResNet50 features with Logistic Regression, SVM, Random Forest, XGBoost, and K-Means.
  • Integrated YOLOv8 and Grad-CAM to support detection and visual explanation.
ResNet50 · YOLOv8 · Grad-CAM · Flask · ML Classifiers

Reinforcement Learning Control

Lunar Landing: DQN Variants vs PPO

Comparative RL study evaluating value-based and policy-gradient methods on Gymnasium LunarLander-v3 under a 500-episode training budget.

  • Compared Vanilla DQN, Double DQN, Dueling DQN, PER-DQN, and PPO.
  • Tracked reward curves, success rate, fuel efficiency, compute cost, and stability.
  • Found PPO improved more consistently and achieved measurable landing success.
DQN · Double DQN · Dueling DQN · PPO · Gymnasium
